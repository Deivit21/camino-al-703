# Camino al 70.3

Mi cuaderno de entrenamiento para llegar al medio Ironman 70.3 de mayo de 2027, pasando por dos 10K, una media maratón y un triatlón olímpico.

**Ver la app:** https://deivit21.github.io/camino-al-703/

## Qué hay aquí

| Carpeta | Qué es |
|---|---|
| `index.html` | La app: plan semana a semana, sesiones del día, comida y geles, zonas, rutina de cadera, técnica de carrera y guías. Está pensada para el móvil. |
| `zwift/` | Los entrenamientos de rodillo en formato `.zwo` para importarlos en Zwift. |
| `resumen-diario/` | El código del resumen diario: descarga mis datos de Garmin Connect (Personal API), compara cada sesión con las parecidas, calcula carga, VFC, sueño y estrés, y prepara el panel con las gráficas. |
| `herramientas/` | Un script para reparar los archivos de Zwift que Garmin Connect no acepta. |

## Lo que no está

Esta es una copia pública de la app **sin mis datos personales**: no incluye mi registro de entrenamientos, mis datos de Garmin (sueño, VFC, pulso, GPS) ni los informes diarios. Esos se quedan en privado.

La versión que uso yo funciona dentro de claude.ai y guarda el registro allí. En esta copia todo lo que apuntes (sesiones hechas, notas, comidas) se guarda solo en tu navegador, y las funciones que preguntan a Claude no están disponibles.
